## 文档纪律（坚持「真相源自一处」）

1. **三份真源互不重叠**：产品决策 → `UPGRADE-0.4.0.md` §一；代码结构 → `CODE-WIKI.md`；构建发布 → `BUILD-GUIDE.md`。任何新增结论先归入对应真源，不在别处另起一份。
2. **无重复源**：同一主题只允许一份权威文档。历史过程稿一律进 `archive/`，不留在活跃区造成误导。
3. **死链即修**：任何文档引用其他文件须用相对路径且目标存在；发现引用已删/已移文件立即改。
4. **落点唯一**：新增文档一律进 `docs/`，禁止在仓库根目录或 `sensend-release/` 散放。
5. **过时即改**：方案落地后同步更新对应真源；不再维护的引用标注「已并入 / 已删除」。
